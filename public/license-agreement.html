ข้อตกลงใบอนุญาตการใช้งานซอฟต์แวร์

Goldenmole Dashboard · อัปเดตล่าสุด: 13 กรกฎาคม 2026

1. บทนำและการยอมรับข้อตกลง

ข้อตกลงใบอนุญาตการใช้งานซอฟต์แวร์ฉบับนี้ (“ข้อตกลง”) เป็นสัญญาระหว่าง Goldenmole (“ผู้ให้สิทธิ์”) กับผู้ใช้ที่ได้รับอนุญาต (“ผู้ใช้”) สำหรับแอปพลิเคชัน Goldenmole Dashboard (“แอป”) รหัสแพ็กเกจ com.goldenmole.dashboard

แอปนี้เป็นเครื่องมือบริหารจัดการโครงการก่อสร้างภายในองค์กร Goldenmole โดยเฉพาะผู้ดูแลระบบ (Admin) ที่ได้รับมอบหมายเท่านั้น การดาวน์โหลด ติดตั้ง เข้าสู่ระบบ หรือใช้งานแอปถือว่าผู้ใช้ยอมรับข้อตกลงนี้ทั้งหมด หากไม่ยอมรับ กรุณาหยุดใช้งานและถอนการติดตั้งแอปทันที

2. การมอบสิทธิ์การใช้งาน

ภายใต้ข้อตกลงนี้ ผู้ให้สิทธิ์มอบสิทธิ์การใช้งานแบบ จำกัด ไม่ผูกขาด ไม่สามารถโอนได้ และเพิกถอนได้ ให้ผู้ใช้ที่ได้รับอนุญาตจากองค์กรเท่านั้น เพื่อติดตั้งและใช้งานแอปบนอุปกรณ์ iOS ที่ผู้ใช้เป็นเจ้าของหรือควบคุม สำหรับวัตถุประสงค์ทางธุรกิจภายในของ Goldenmole เท่านั้น

สิทธิ์นี้ ไม่รวม การให้สิทธิ์ย่อย การจำหน่าย การให้เช่า การให้บริการแบบ SaaS ต่อบุคคลภายนอก หรือการใช้งานเพื่อวัตถุประสงค์อื่นนอกเหนือจากที่องค์กรกำหนด

3. คุณสมบัติผู้ใช้และการเข้าถึง

  • ผู้ใช้ต้องเป็นพนักงาน ผู้รับเหมา หรือบุคคลที่องค์กร Goldenmole อนุมัติเป็นผู้ดูแลระบบหรือผู้ใช้ที่ได้รับอนุญาต
  • การเข้าสู่ระบบต้องใช้บัญชีที่องค์กรจัดสรรผ่านระบบ Supabase เท่านั้น
  • ผู้ใช้ต้องรักษาความลับของชื่อผู้ใช้ รหัสผ่าน และข้อมูลเซสชัน ไม่เปิดเผยหรือแชร์ให้บุคคลที่สาม
  • ผู้ใช้ต้องแจ้งองค์กรทันทีหากพบการเข้าถึงโดยไม่ได้รับอนุญาตหรือการรั่วไหลของข้อมูล

4. ข้อจำกัดการใช้งาน

ผู้ใช้ตกลงที่จะ ไม่ กระทำการดังต่อไปนี้ เว้นแต่ได้รับความยินยอมเป็นลายลักษณ์อักษรจากผู้ให้สิทธิ์

  • คัดลอก ดัดแปลง แจกจ่าย ขาย ให้เช่า หรือส่งต่อแอปหรือส่วนหนึ่งส่วนใดของแอปแก่บุคคลภายนอก
  • ถอดรหัส ดีคอมไพล์ แยกส่วน หรือพยายามค้นหารหัสต้นฉบับ (reverse engineering) ของแอป
  • ลบหรือแก้ไขประกาศลิขสิทธิ์ เครื่องหมายการค้า หรือข้อความแสดงความเป็นเจ้าของ
  • ใช้แอปเพื่อวัตถุประสงค์ที่ผิดกฎหมาย ละเมิดสิทธิ์ของผู้อื่น หรือเป็นอันตรายต่อระบบและข้อมูลขององค์กร
  • พยายามเข้าถึงระบบ ฐานข้อมูล หรือ API โดยไม่ได้รับอนุญาต รวมถึงการ bypass มาตรการรักษาความปลอดภัย
  • ใช้แอปเพื่อเก็บหรือประมวลผลข้อมูลของบุคคลภายนอกที่ไม่เกี่ยวข้องกับงานของ Goldenmole

5. ความเป็นเจ้าของซอฟต์แวร์และข้อมูล

แอป รวมถึงซอร์สโค้ด การออกแบบ กราฟิก โลโก้ เอกสาร และทรัพย์สินทางปัญญาอื่น ๆ เป็นทรัพย์สินของผู้ให้สิทธิ์หรือผู้ให้สิทธิ์ย่อย และได้รับความคุ้มครองตามกฎหมายลิขสิทธิ์ ข้อตกลงนี้ไม่ได้โอนกรรมสิทธิ์ใด ๆ ให้ผู้ใช้ นอกจากสิทธิ์การใช้งานตามที่ระบุไว้เท่านั้น

ข้อมูลธุรกิจ ที่ผู้ใช้ป้อน ดึง หรือจัดการผ่านแอป (เช่น ข้อมูลพนักงาน โครงการ รายรับ-รายจ่าย) เป็นขององค์กร Goldenmole ผู้ใช้ไม่มีสิทธิ์เรียกร้องความเป็นเจ้าของซอฟต์แวร์จากการใช้งานข้อมูลดังกล่าว

6. การอัปเดตและการบำรุงรักษา

ผู้ให้สิทธิ์อาจเผยแพร่อัปเดต แพตช์ หรือเวอร์ชันใหม่ของแอปผ่าน App Store หรือ TestFlight การอัปเดตอาจจำเป็นเพื่อความปลอดภัย ความเข้ากันได้ หรือการปรับปรุงฟีเจอร์ ผู้ใช้ควรติดตั้งอัปเดตที่แนะนำเพื่อใช้งานอย่างต่อเนื่อง

ผู้ให้สิทธิ์ไม่มีภาระผูกพันที่จะต้องพัฒนาฟีเจอร์ใหม่หรือให้การสนับสนุนแบบไม่จำกัดเวลา แต่จะพยายามรักษาความพร้อมใช้งานของระบบตามความสามารถที่สมเหตุสมผล

7. การทดสอบผ่าน TestFlight

หากผู้ใช้เข้าร่วมทดสอบผ่าน Apple TestFlight แอปอาจอยู่ในสถานะทดลอง (beta) ฟีเจอร์อาจเปลี่ยนแปลง หยุดทำงาน หรือถูกถอนได้โดยไม่ต้องแจ้งล่วงหน้า ข้อมูลจากการทดสอบอาจถูกใช้เพื่อแก้ไขข้อบกพร่องและปรับปรุงแอปเท่านั้น

8. การปฏิเสธการรับประกัน

แอปจัดให้ “ตามสภาพที่เป็น” (AS IS) และ “ตามที่มีให้” (AS AVAILABLE) โดยไม่มีการรับประกันใด ๆ ทั้งโดยชัดแจ้งหรือโดยนัย รวมถึงแต่ไม่จำกัดการรับประกันด้านความเหมาะสมสำหรับวัตถุประสงค์เฉพาะ ความถูกต้องของข้อมูล หรือการทำงานที่ไม่หยุดชะงัก

ผู้ใช้รับทราบว่าการตัดสินใจทางธุรกิจที่อิงจากข้อมูลในแอปเป็นความรับผิดชอบขององค์กรและผู้ใช้เอง ควรตรวจสอบข้อมูลสำคัญก่อนนำไปใช้ในการบัญชี กฎหมาย หรือสัญญา

9. การจำกัดความรับผิด

ภายใต้ขอบเขตสูงสุดที่กฎหมายอนุญาต ผู้ให้สิทธิ์ กรรมการ พนักงาน ผู้รับเหมา และผู้ให้บริการที่เกี่ยวข้อง จะไม่รับผิดชอบต่อความเสียหายทางอ้อม ความเสียหายพิเศษ ความเสียหายที่เป็นผลสืบเนื่อง การสูญเสียกำไร ข้อมูล หรือโอกาสทางธุรกิจ แม้จะได้รับแจ้งถึงความเป็นไปได้ของความเสียหายดังกล่าว

ความรับผิดรวมสูงสุดของผู้ให้สิทธิ์ต่อผู้ใช้ภายใต้ข้อตกลงนี้ (หากมี) จำกัดไม่เกินจำนวนเงินที่ผู้ใช้ชำระให้แก่ผู้ให้สิทธิ์สำหรับแอป ซึ่งในกรณีแอปภายในองค์กรนี้ อาจเป็นศูนย์บาท

10. การสิ้นสุดสิทธิ์

สิทธิ์การใช้งานจะสิ้นสุดทันทีเมื่อเกิดเหตุการณ์ใดเหตุการณ์หนึ่งดังต่อไปนี้

  • ผู้ใช้ละเมิดข้อตกลงนี้
  • องค์กรเพิกถอนสิทธิ์การเข้าถึงหรือยกเลิกบัญชีผู้ใช้
  • ผู้ใช้ลาออกหรือสิ้นสุดความสัมพันธ์กับองค์กร Goldenmole
  • ผู้ให้สิทธิ์ยกเลิกหรือหยุดให้บริการแอป

เมื่อสิทธิ์สิ้นสุด ผู้ใช้ต้องหยุดใช้งานแอป ถอนการติดตั้ง และลบข้อมูลเซสชันที่เก็บบนอุปกรณ์ ข้อที่เกี่ยวกับความเป็นเจ้าของ การจำกัดความรับผิด และกฎหมายที่ใช้บังคับยังคงมีผลต่อไป

11. กฎหมายที่ใช้บังคับและการระงับข้อพิพาท

ข้อตกลงนี้อยู่ภายใต้กฎหมายแห่งราชอาณาจักรไทย ข้อพิพาทที่เกิดจากหรือเกี่ยวข้องกับข้อตกลงนี้จะพยายามระงับโดยการเจรจาเป็นอันดับแรก หากไม่สามารถตกลงกันได้ภายในระยะเวลาที่สมเหตุสมผล ให้เขตอำนาจศาลที่มีเขตอำนาจในประเทศไทยเป็นผู้พิจารณา

12. นโยบายความเป็นส่วนตัว

การเก็บ ใช้ และคุ้มครองข้อมูลส่วนบุคคลของผู้ใช้เป็นไปตาม นโยบายความเป็นส่วนตัว ของ Goldenmole Dashboard ซึ่งถือเป็นส่วนหนึ่งของข้อตกลงนี้โดยอ้างอิง

13. การเปลี่ยนแปลงข้อตกลง

ผู้ให้สิทธิ์อาจแก้ไขข้อตกลงนี้เป็นครั้งคราว การเปลี่ยนแปลงที่สำคัญจะแสดงบนหน้านี้พร้อมวันที่อัปเดตล่าสุด การใช้งานแอปต่อไปหลังมีการเปลี่ยนแปลงถือว่าผู้ใช้ยอมรับข้อตกลงฉบับที่แก้ไขแล้ว
